# 停一下 · Pause Before Scroll

看短视频前停几秒，为这次观看设一个结束点。手机优先，无需注册；微信聊天照常使用。

网页发布地址：<https://chenhenry0429.github.io/pause-before-scroll/>。

请分享上面的网址，使用手机浏览器打开。不要把“另存为”的 HTML 文件当作安装包发送；文件管理器打开的本地副本可能只有外观，无法计时或响应按钮。v0.3.1 已加入本地副本提示、脚本启动诊断和旧版浏览器兼容处理。

## 使用

1. 选择视频号或哔哩哔哩、计划观看的分钟数，停顿后决定是否开始。
2. 首次在手机上使用，到“我的约定”设置通知。iPhone 需先添加到主屏幕，再从图标打开；安卓可安装到桌面或使用支持推送的浏览器。
3. 先发送一条测试提醒，确认手机收到；每次计时显示“后台提醒已安排”后再离开网页。
4. 回来结束计时并留下自评，查看近七天记录，也可以导出、清除本机数据。
5. “反馈与建议”支持匿名提交，看到回执编号才表示已保存。

网页不能识别、测量或封锁其他 App。推送受网络、专注模式和手机系统影响；需要严格计时时可同时使用系统计时器。

## 创作者查看反馈

电脑网页底部有“创作者后台”，也可打开 `creator.html`。输入创作者访问密钥后查看、搜索和筛选反馈；密钥仅在当前页面内存中使用，退出或刷新后需重新输入。手机界面隐藏管理入口，仍可提交反馈。

不要把创作者访问密钥、服务密钥、VAPID 私钥或反馈导出上传到 GitHub。仓库只有源代码，公开页面不内嵌反馈。普通使用者无需 GitHub 或 ChatGPT 登录。

## 数据与迁移

观看记录只保存在当前浏览器，不上传。换网址、设备或清理浏览器数据后记录不会自动转移；切换旧站点前请先导出。新网址需重新添加到主屏幕和开启通知。

匿名反馈存储在作者 Cloudflare 账号下的 SQLite Durable Object 数据库，字段为分类、标题、正文、提交时间、回执、版本和内容校验值。提交凭据及每日加盐的网络地址摘要用于限制滥用，不保存原始网络地址；凭据一小时有效，过期自动清理。托管服务仍可能记录请求安全日志。反馈不公开，也不自动附带观看记录。

通知服务只接收随机设备凭据、通知地址、计时编号和结束时间。通知地址发送或取消后删除；状态最长保留 24 小时，通知启用状态在最后使用后保留 30 天。旧版提醒接口保留，以免影响已经安装旧版的用户。

## 发布与开发

- `docs/` 是完整静态网页，GitHub Pages 选择 `main` 分支的 `/docs` 目录即可发布。
- `service/` 是 Cloudflare Worker，提供匿名反馈、受保护的创作者查询，以及定时加密推送。
- `lib/`、`tests/` 是查询逻辑与自动检查。

```sh
npm ci
npm run build
npm ci --prefix service
npm test
npm run check
```

修改 `docs/*.mjs` 后运行 `npm run build`，把生成的 `docs/app-compat.js`、`docs/sw.js` 和更新后的 `docs/index.html` 一起提交。手机页面使用单一普通脚本，构建目标为 Chrome 70 / Safari 13；这不是对所有同版本手机或浏览器的兼容保证。`scripts/sw-source.js` 是通知脚本源文件。基础计时与通知初始化分开，缺少推送能力时仍可计时和回顾；弹窗和随机编号也提供兼容处理。

部署服务时使用官方 Wrangler CLI：在 `service/` 运行 `npx wrangler deploy`。部署者须先登录 Cloudflare，并配置 `SERVICE_SECRET`、`VAPID_PUBLIC_KEY`、`VAPID_PRIVATE_KEY`、`CREATOR_KEY` 四项机密。已有部署更新时保留现有机密和 Durable Object 类的迁移历史。`PUBLIC_ORIGIN` 为允许的网页来源；`docs/api.mjs` 只包含公开服务地址，不含密钥。

该项目不依赖 Sites 或 ChatGPT 登录。GitHub Pages 只托管静态页面，数据库和通知由 Cloudflare 提供。当前域名和跨域来源用于本项目；分叉后须改为自己的地址和账户。

## v0.4.0 手机使用与安卓安装版

- 网页打开即可点击「立即开始」。在「安装与到点提醒」里按设备提示添加到桌面、开启通知或下载 APK。
- Android 8.0 及以上可以试用独立安装版。它使用本地打包的界面和计时数据，不需要 Google 服务。网页和 APK 的记录分别保存在各自的存储空间。两边均可导出记录。
- Android 13 及以上的安装版需要通知权限。Android 12 及以上未授权准确闹钟时，会安排可能延迟的提醒。系统免打扰、省电策略、强制停止或重启可能影响提醒；启动新计时前先完成上一次回顾。收到测试通知后，请在设置中确认。
- 浏览器推送只有用户看到通知后才能确认送达。网页和安卓安装版都可以跳过通知直接计时。
- Windows 构建见 [android/README.md](android/README.md)。公开仓库只保留代码和已经签名的发布包，签名材料须保存在仓库之外。
